# Daily Motivation

A single page that shows one motivational quote per day — matched to the themes the world
is talking about that day — with a related photo.

## How it works

Static site, no backend. A daily GitHub Action run regenerates `data/daily.json`,
commits it, and deploys to GitHub Pages.

**Pipeline** (all keyword-based, no LLM at runtime — deterministic & free):

1. Fetch world headlines from Google News RSS (keyless).
2. Score them against a **theme whitelist** (`data/themes.json`) to pick the day's theme
   — e.g. perseverance, change, courage, rest, hope, unity, innovation…
3. Choose a quote from `data/quotes.json` tagged with that theme, **excluding anything
   used in the last 30 days** (cooldown), deterministic per date.
4. Fetch a correlated image: Unsplash by theme if `UNSPLASH_ACCESS_KEY` is set, else a
   stable Picsum placeholder.
5. Write `data/daily.json` + append to `data/history.json`, commit, deploy.

## Layout

```
index.html              site page (EN/RU toggle)
style.css               styles
app.js                  loads daily.json, renders quote, language toggle
data/themes.json        theme whitelist: keywords + unsplash query + labels
data/quotes.json        quote pool (EN/RU, tagged)   <-- generated by AI agent, commited
data/daily.json         today's pick (generated)
data/history.json       rolling archive for the 30-day cooldown (generated)
generator/daily.py      the daily generator (stdlib only)
.github/workflows/daily.yml  nightly run + deploy
```

## Local run

```bash
# first time: install python deps (none beyond stdlib)
# with Unsplash key (optional, otherwise Picsum fallback):
UNSPLASH_ACCESS_KEY=xxx python3 generator/daily.py
# for a specific date:
python3 generator/daily.py --date 2026-09-16
```

Preview locally:

```bash
python3 -m http.server 8000      # open http://localhost:8000
```

## GitHub setup (one-time)

1. Push `main`.
2. In repo **Settings → Pages**, set source to **GitHub Actions**.
3. (Optional) Add repo secret `UNSPLASH_ACCESS_KEY` for real photos.
4. Done — the nightly Action regenerates + redeploys automatically.

## Adding quotes

Edit `data/quotes.json` (or ask your AI agent to regenerate it). Each entry needs a stable
unique `id`, `en`, `ru`, `author`, and 1–3 `tags` drawn from the theme names in
`data/themes.json`.
